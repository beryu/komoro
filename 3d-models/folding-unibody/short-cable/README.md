# 折りたたみC案 — 101.6 mm FFSDと内部給電

手持ちの101.6 mm品を基準に、既存PCBを加工せず、電池下を通る連続したリボンケーブルをモデル化した。元の前端迂回案は親ディレクトリへ残し、この案のCAD・Blender・画像・検証をここへ分離している。印刷・実ケーブルでの嵌合・耐久確認前の試作案。

[Blenderモデル](generated/komoro-folding-101mm.blend) ／ [FreeCAD](generated/folding-unibody-rev-a.FCStd) ／ [開状態](generated/open-render.png) ／ [閉状態](generated/folded-render.png)

購入部品・製造先・1台分の数量は[購入リンク付き部品表](PARTS.md)を参照。現行分割版からの流用とC専用品、未選定品・実機確認事項を分けて記載している。

## 配置の変更

- 右PCB・右キー領域を奥へ6 mm移し、左右コネクタの前後位置をそろえた。基板の銅箔・穴・部品位置は変更していない。
- 電池を中央ケースの右寄り、電源回路を左側の前後へ配置した。電池ホルダー底を1 mm上げ、電池下の配線室とその天井を確保した。
- ケーブル用の可動空間を左右コネクタ近くへ移し、前端まで迂回する旧通路を廃止した。左トレーの旧下面配線室と底ぶたは一体の床へ戻した。
- 電源ふたを前後2枚へ分け、間をケーブルの可動空間として開けた。スイッチは左側面から操作する。
- 右端末手前にも緩やかな上下の曲げを設け、余長を分散した。電池カバー右側の開放された下端に逃げを追加し、上部2.3 mmの縁を残した。ケーブルは電池窓の上を横切らない。
- 5V/GND用の2本の線も床とPCB後端を通す予約空間を設けた。上面の長い給電ガイドは設けていない。

| 電池中心 | X=10、Z=12 mm |
| 電池カバー最高部 | Z=19 mm |
| ホルダー底面 | Z=4.5 mm |
| 電池下のリボン中心 | Z=2.4 mm |

| 回転軸 | Z=18.5 mm、既存と同じ |

右PCBの移動で奥行きが増える。全体高さと収納厚は従来と同じ。閉状態のSTL/Blenderの頂点幅は約166.6 mmで、FreeCADの保守的な包絡幅166.8 mmと約0.2 mm異なる。

## ケーブルの検証範囲

ケーブル幅は最大7.7978 mm、厚さは最大0.7366 mmを使用した。メーカーの[線材図](https://suddendocs.samtec.com/prints/cb-xx-30-7-38-025-gr.pdf)、[アセンブリ図](https://suddendocs.samtec.com/prints/ffsd-xx-x-xx.xx-01-x-x-xxx-mkt.pdf)を参照。両端のコネクタ本体長は各3.05 mmとしている。図面上の公称101.6 mmに合わせており、数値化した中心線の合計は約101.598 mm（端末込み、円弧の離散化誤差を含む）。

幅方向を回転軸Yと平行に保った帯として、曲げやすい方向の曲げだけを使う。リボンを面内へ曲げたり、伸ばしたりして前後のずれを吸収するモデルではない。最小曲げ半径3 mmはこの案の仮定であり、Samtecが保証する繰り返し曲げ半径ではない。

[形状の検証](generated/layout-validation.json)では、保存したCADを読み直して0〜180°を5°ごと、37姿勢で確認した。リボンとケース・右側部品・左右PCB・電池・ホルダーの体積干渉は0。印刷部品同士の開状態の重なり、回路部品の収納、給電線の予約空間も確認した。閉時のキー押下は最大1.0 mmで、仮定した2 mm以内。

[長さと自己接触の検証](generated/cable-length-validation.json)では、37姿勢の公称長維持とサンプル間の自己接触を確認した。非近傍の中心線サンプル間距離からリボン厚を引いた余裕は最小約3.03 mm。連続した弾性体の運動解析、材料応力・接点の引張り・疲労寿命の計算ではない。

[電池交換の検証](generated/battery-service-validation.json)では、フックを解除した状態で、カバーを0〜25 mm持ち上げても固定ケーブル・ホルダー・電池・本体に当たらないことを確認した。実際の爪のたわみ、保持力、印刷公差は未確認。

**実物との合わせ込みが残る点：**

- ソケットの嵌合高さ・ケーブル出口の方向は未実測。現在はケーブル出口中心Z=12.5 mmの仮定。
- 公称101.6 mmの経路を検証した。長さ公差±3.175 mmの全範囲をこの経路で吸収できる保証はない。手持ちケーブルの実長・端末を仮組みして調整する。
- 76.2 mm品はこの案の対象外。101.6 mmの代わりに差し込めるモデルではない。
- 細い線の曲げ、はんだ・絶縁材、PCB下面の部品や端子の突出、印刷強度・摩耗は実機確認が必要。給電線予約空間は被覆外径1 mm以下の2本を想定。
- 電池ホルダーは従来と同じく樹脂端部を低くした未実測形状。金属接点と固定部は残す。

## 見方と再生成

Blenderの `01_Open` と `02_Folded` が通常の開閉状態。`03_Underside_covers_hidden` は右の底ぶたを隠し、`04_Battery_cover_removed` は独立した電池カバーを隠す。リボンは灰色。配線確認画像は同じモデルのケースと電池を透過し、キーを隠してリボンだけをオレンジ色にした説明用画像で、印刷色の指定ではない。

再生成の順番：

1. 親ディレクトリの `generate.py` で元のCADを生成する。
2. 通常のPython（NumPy/SciPy）で `solve-cable.py`、`check-cable.py` を順に実行する。37姿勢の経路と公称長・自己接触の検証を保存する。
3. FreeCADのPythonで、このディレクトリの `generate.py`、`check-layout.py`、`check-battery.py`、`check-c-design.py`、`check-exports.py` を順に実行する。
4. 環境変数 `FOLD_MODEL_DIR` にこのディレクトリの絶対パスを指定し、Blenderで親の `export-blender.py` を実行する。
5. Blenderで `check-blender.py` を実行する。親の `render-open-folded.py` は同じ環境変数と `FOLD_REVIEW_FILE=komoro-folding-101mm.blend` を指定する。配線確認画像は `render-cable.py` で生成し、通常のPython（Pillow）で `compose-routing.py` を実行して比較画像を更新する。

底ぶたはM2×3、電源ふたはM2×4を想定する。底ぶたの2本は給電線から離したY=64 mmに置き、専用のねじボスを設けた。奥へ張り出していた給電線用の底ぶた・2個のボスは廃止した。ねじ軸の包絡と線の重なりも確認する。上記の全体寸法は印刷形状の包絡で、ねじ頭や追加する足は含まない。

STLは `generated/` 内の10個の印刷部品。ケーブル・基板・電池・スイッチ類は参照形状で印刷しない。親ディレクトリの旧部品と混ぜて組み立てない。

## 承認済みC外観とXIAO内部給電

`c-design.py` がPCB由来の版管理された寸法だけからC案を生成する。承認時の一時CADや一時スクリプトは再生成に使わない。左右トレーの旧split用縦溝・内側補強リブと4個ずつの丸い床面磁石穴、左トレーの床下1.2 mmの旧配線室の帯を除いた。ヒンジ側の閉止用磁石・軸穴・閉止面、元のPCBとキー配置、トラックボール、AAAの開口と電池カバー形状は維持する。split版と親の折りたたみ出力は変更しない。

ヒンジ肩の頂部はZ=19.7 mmより上だけを小さくテーパーにする。ピン穴上端Z=19.55 mm以下には触れない。ラッチふたの前・側縁は0.3 mm（ねじ穴に近い後縁を保持）、前後の電源ふたは0.65 mmの実体面取りとし、丸いねじ穴と取付面を保持した。承認画像のメッシュ全体を縮める処理とはこの点が異なる。最高部や機構寸法を変える大きな変形は採用していない。

GND/VBUSはそれぞれ被覆外径1 mmの公称実体。溝半径は0.66 mmで、承認参照の0.65 mmから0.01 mm拡げ、既存カバー面に接する微小なSTL開口を回避した。電源室の後ろから内壁沿いに進み、右PCB後端を回って、既存の上カバーの側方空間と小さな内側リップの内側でXIAOへ戻す。終端は元の座標系でGND側Y=70.48、VBUS側Y=73.02 mmへの接近位置。実際のパッドやはんだフィレットの形状は表していない。長い上面導管や給電線用の下面延長はなく、中央のFFSD着脱底ぶたを残す。

[`c-design-validation.json`](generated/c-design-validation.json) は保存CADを再読込し、全10部品の閉じた単一ソリッドとSTL、旧底面形状の消失、8個の床面磁石穴の充填、ねじ穴の開口、公称給電線と固定部品、および0〜180°の5°刻みと閉じ際の0.5°刻みを確認する。FFSD・キー押下・電池アクセスは既存の検証を併用する。

組立では右PCB・上板を取り付ける前に未接続の線を配置し、必要な短い通路には未はんだの端を通す。XIAO側のはんだ付けと絶縁の後に上板を取り付ける想定であり、端末付き線を細い穴へ通せるとは確認していない。実物の組立アクセス、USBプラグ外形、端子・はんだ高さ、線の固定とストレインリリーフは仮組みで確認する。

**製作前の限界：** 線間余裕は0.0822 mm、可動部との最小余裕は0.480 mm。仮定したスイッチ外形との余裕は0.050 mm、右PCBとXIAO外形には各0.450 mm。中心線の最小曲げ半径はGNDが0.963 mm、VBUSが1.350 mmで、1 mm線には非常に小さい。正確な生成値はJSONに記録する。印刷誤差・線径公差・被覆の変形・はんだや接着剤の厚みを吸収できる保証はない。曲線の最小半径は幾何学的な値で、使用する線材の許容曲げ半径や反復寿命ではない。線材の選定、絶縁、実USBアクセス、印刷強度とヒンジ・ラッチの摩耗、電池着脱力を実機で確認する。本案は製作実証済みではない。

再生成後は `update-manifest.py` を最後に実行する。STEPは全10部品を本案の `generated/` に保存し、STL・FreeCAD・Blender・検証JSONと一緒に配布する。

### upstream機構の比較記録

`check-preservation.py --baseline-cad <比較元.FCStd> --baseline-commit <SHA>` は比較元を明示して再実行できる。今回の比較元はmaster `10c3bea19c68a638a8abf6724226711448d78b1f` の本ディレクトリのCAD。`git show <SHA>:3d-models/folding-unibody/short-cable/generated/folding-unibody-rev-a.FCStd` で取り出せる。記録は [`mechanical-preservation-validation.json`](generated/mechanical-preservation-validation.json)。元のPCB・キー・部品参照27個、電池カバー・左上板・ラッチスライダ、軸付近の機構面とふた取付面の体積差を確認した。既存USB開口と全高プラグ切欠きの予約空間も狭めておらず、給電線との余裕は開口まで2.772 mm、全高切欠きまでの正確値は同JSONに記録する（実USBプラグの保証ではない）。

このMacではFreeCAD Pythonに `PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib` を指定する。Blenderの実行ファイルは `/Applications/Blender.app/Contents/MacOS/Blender`。再生成は作業用チェックアウトで行い、親の既存成果物の更新は本案の変更に混ぜない。
